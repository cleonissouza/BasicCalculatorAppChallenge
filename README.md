# BasicCalculatorAppChallenge

This project is a basic calculator app developed as part of a challenge from Escola Nova Era Tech.

The goal of this challenge was to practise and test my knowledge of Android development using XML and Kotlin.

## Technologies used

- Kotlin
- XML
- LinearLayout
- TextView
- GridLayout
- Button
- findViewById

## What I practised

- Creating layouts with XML
- Organising buttons using GridLayout
- Displaying numbers and results with TextView
- Handling button clicks with Kotlin
- Connecting XML views to Kotlin using findViewById
- Building basic calculator logic

## About the project

The app allows the user to perform simple calculator operations.  
This challenge helped me improve my understanding of how the UI connects with Kotlin code in Android.

## Status

Project completed as a learning challenge.
